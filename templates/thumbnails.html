How to download a YouTube thumbnail

  1. Copy any YouTube video URL

    Watch URLs, youtu.be short links, embed URLs and Shorts links are supported.

  2. Paste it into the box above

    The tool checks YouTube's public thumbnail variants for the video.

  3. Open or download a size

    Choose an available size. If your browser blocks direct downloads, open the image and use Save image as.

Why use YouTube Thumbnail Downloader?

Creators, designers, bloggers and students often need thumbnail assets for their work. Preview the image sizes YouTube makes available without an account or API key.

Frequently Asked Questions

What thumbnail sizes does this tool support?

The tool checks maximum, standard, high, medium and default YouTube thumbnail variants. Not every video has every size.

Is it legal to download a YouTube thumbnail?

Respect the creator's rights and YouTube's terms when using thumbnail images.

Why do some videos not have a max-resolution thumbnail?

Some videos do not have every resolution available. The unavailable variants are marked instead of shown as valid images.

Can I download the animated "hover" preview?

No. This tool provides static thumbnail images only.

Do I need an API key or an account?

No API key or account is required to preview public thumbnail URLs.

Do you store the URLs I paste?

The video ID is used to construct public image URLs and is not stored by this app.
